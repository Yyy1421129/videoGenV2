# videoGenV2

写实流水线在 `/home/yi.yang/src/videoGenV1`。本目录用固定的 Deepseek 鲸鱼娘，按提示词生成不同主题的短视频。画面是 Wan2.2 TI2V-5B 加动漫 LoRA，配音是 CosyVoice2。口型留到动作稳定之后。

角色图在 `project/deepseek/`：`deepFront.jpg` 是正面，`deepseekBack.jpg` 是背面。一次生成只用其中一张，由镜头的 `view` 决定。身份描述写在 `project/deepseek/character.json`，不交给语言模型重写。

Deepseek 只负责把主题拆成台词、场景和动作。它不生成像素，也不生成波形。

Wan 代码在 `/home/yi.yang/src/videoGenV1/repos/Wan2.2`。环境是 `videogen-v2`，视频权重在 `/gpfs/sjtu/audiocc/home/yi.yang/videogen/models/Wan2.2-TI2V-5B`，动漫 LoRA 在 `/gpfs/sjtu/audiocc/home/yi.yang/videogen-v2/models/lora/`。CosyVoice2 权重在 `/gpfs/sjtu/audiocc/home/yi.yang/videogen/models/CosyVoice2-0.5B`。

## 画面模型：Wan2.2 TI2V-5B

这条流水线用的是 5B 的密集模型，不是 Wan2.2-A14B。A14B 是高噪声专家加低噪声专家的 MoE，总参数约 27B，本目录没有加载它。

TI2V-5B 由三块组成，数字来自 `wan/configs/wan_ti2v_5B.py`：

| 模块 | 本机配置 | 作用 |
| --- | --- | --- |
| umT5-XXL 编码器 | `models_t5_umt5-xxl-enc-bf16.pth`，推理时放在 CPU | 把英文提示编码成交叉注意力条件 |
| Wan2.2 VAE | 时间 × 高 × 宽压缩 4×16×16 | 在 latent 里生成，再解码成像素 |
| DiT | 30 层，宽度 3072，24 头，FFN 14336 | 在 latent 上按 flow matching 去噪 |

patch 是 1×2×2，所以进 DiT 之前，时间再压 1 倍、空间再压 2 倍。算上 VAE，总压缩是 4×32×32。默认 24 fps、121 帧，大约 5 秒。官方支持的尺寸是 `704*1280` 和 `1280*704`。

有参考图时，第一帧用这张图的 VAE latent，后面的帧从噪声开始。没有参考图时，整段都从噪声开始。按主题出片时仍带一张参考图。角色 LoRA 的检查可以在 `shot.json` 里写 `"text_only": true`，这时不传图，第一帧也不会被钉住。采样器是 UniPC，分类器无关引导把有条件和无条件的结果做差。配置里的默认是 50 步、guide scale 5；当前镜头用 40 步、guide scale 6。

预训练目标是 flow matching：在 VAE latent 上学习从噪声走向视频的速度场。官方说明里，5B 和 14B MoE 共用升级后的训练数据；5B 本身没有第二套专家。本集群没有重训这个底模。

动漫 LoRA 是现成权重 `wan_2.2_B_anime_v01_000153000.safetensors`。`run_lora.py` 把它的 A、B 矩阵乘进 DiT 的线性层，强度 0.6，只影响这次进程里的副本，不改底模文件。它负责赛璐璐画风。鲸鱼娘的脸和衣服来自参考图，不是这条 LoRA 单独学会的。角色 LoRA 另训，不和这条风格 LoRA 叠在同一次生成里。做法和现有数据见下面两节。

## 角色 LoRA 怎么训

脚本是 `scripts/train_character_lora.py`，提交文件是 `/home/yi.yang/slurm/videogen-v2-lora-train.sbatch`。底模仍是 TI2V-5B。T5、VAE 和 DiT 原权重都冻结。默认训练秩 16 的 LoRA，加在每一层的 self-attention、cross-attention 的 q、k、v、o，以及 FFN 的两层线性上，共 300 层、约 4030 万个可训练参数。`--attn-only` 会去掉 FFN，剩下 240 层、约 2360 万参数。不加载现成的动漫 LoRA。每次都从头训，不续上一份权重。

一条样本是片段里的 49 帧，缩到 480×832。49 等于 4n+1，边长能被 32 整除，VAE 才能编码。像素先变到 -1 到 1，再编成 latent。flow matching 用 shift 5：`x_t = (1-sigma) * 干净latent + sigma * 噪声`，网络预测的速度是 `噪声 - 干净latent`。窗口按帧号截取，不按时间戳，避免片段末尾少一帧时整次训练退出。

起点在片段里每隔 4 帧均匀取一个。更早按帧差挑窗口时，抽到的正是手脚拉长的帧，已经停用。片段本身按 `sample_weight` 抽。`--downweight` 把 `ref_back_01.mp4`、`seedance_backwalk_01.mp4`、`seedance_pier_01.mp4`、`seedance_swing_01.mp4` 的权重除以 3，这四条会把人缩小或裁掉身体。

脚本里有三种目标，一次只用一种：

- 默认的 `--anchor-prob`（f49a 用 0.25）：这个比例的步数把第一帧 latent 换成对应机位的设定图，时间步为 0，不计入损失。其余步数整段加噪，每一帧都计入损失。
- `--pin-first`：每一步都锁住第一帧。默认锁的是窗口自己的第一帧；`--sheet-prob` 再按比例换成设定图。f49b 用了这个，并加了 `--attn-only`。
- `--clip-ref`：`--ref-prob` 的步数从同一段视频里另取一帧，锁进第一帧，这一帧不计入损失，后面仍是这个窗口自己的动作。优先取离窗口至少 16 帧的画面。其余步数整段加噪。不使用白底设定图。f49c 用 `--ref-prob 0.4`。

文本是 `features.json` 里的中文 `caption`，开训前用 CPU 上的 umT5 编一次然后卸掉 T5。每步有 10% 的概率丢掉这句。优化器只看 LoRA 参数，AdamW，学习率 1e-4。注意力块用梯度检查点。权重存成 `diffusion_model.*.lora_A/B`，`run_lora.py` 按 scale 1.0 单独使用。每 200 步另存一个文件。

`run_lora.py` 在传入参考图时仍会把第一帧时间步设为 0，并在每步去噪后写回这张图。`shot.json` 写了 `text_only` 才整段从噪声生成。

## 实验和结果

检查用同一组中文提示词和种子 81，只加角色 LoRA，scale 1.0，不叠赛璐璐 LoRA。书店是正面指向高处的书，走路是左侧面在林荫道上走，雪地是背面蹲下拢雪再站起。早期还有一条雨中月台撑伞。赛璐璐 LoRA 自己的试片留在 `shots/anime-lora/`，当作没有角色 LoRA 时的画风基线。120 步、800 步锁首帧、33 帧和 f49、f49b 的成片已经从仓库拿掉，结论记在这里。f49a 和 f49c 的成片还在 `shots/`。

损失不能跨目标比较。锁住第一帧、并且这一帧不进损失时，数字会低一截，不代表身体更完整。

| 轮次 | 训法 | 结果 |
| --- | --- | --- |
| s120 | 120 步，推理锁参考图 | 人像鲸鱼娘，是因为第一帧被钉住。书店指向很弱，月台伞旁多出一只手，雪地里腿消失 |
| s800 | 800 步，仍然每步锁第一帧 | 损失约 0.19 到 0.155。人更僵，变的主要是背景 |
| f33b | 33 帧，约 1.4 秒，全部帧进损失。38 条、295.4 秒 | 损失 0.301 到 0.286。纯文本能认出这个人。书店几乎不动，书浮在肩旁；月台接近静帧；雪地背面站得住，但没有蹲下去 |
| f49 | 49 帧，按帧差抽窗口。42 条、333.6 秒。800 步 | 损失 0.307 到 0.273。动作变大，身体拆开：书店尾巴离开裙子，林荫道腿交叉拉长，雪地袖口外是肉色长手 |
| f49a | 49 帧，均匀窗口，75% 全加噪，25% 钉设定图。51 条、394.8 秒。注意力和 FFN，300 层 | 损失 0.312 到 0.280。纯文本身份还在，书店指向侧面，走路脚重叠，雪地手臂变成雪板。带设定图时形变少，书店几乎不动 |
| f49b | 每步都钉第一帧：90% 是窗口自己的第一帧，10% 是设定图。只训注意力，240 层 | 纯文本雪地换成了另一个浅色正面人物。带设定图的书店和走路停在立绘姿势附近 |
| f49c | 60% 全加噪，40% 钉同一段里的另一帧。注意力和 FFN 都训。同一批 51 条，从头训 800 步 | 800 步梯度都有效，其中 339 步钉了另一帧。纯文本身份回来了。书店的手能抬起来指向上方，走路在迈步，雪地会蹲下再站起。雪地的肘往后折，手凑到背后。带设定图的走路步子更清楚，书店的手仍指在身侧 |

f49 说明只加长窗口、并专挑动作大的帧，会把片段里已有的坏形变学进去。f49a 把窗口改回均匀抽取，并让四分之一的步看见设定图，身份和大致轮廓比 f49 稳，但设定图把姿势留在站立，雪地的手仍会化掉。f49b 去掉了「从噪声里把这个人画出来」的步，又冻住了前馈网络，纯文本就不再是这条鲸鱼娘；每步都接着窗口自己的第一帧，推理时钉一张站立设定图，后面的画面也不离开这个姿势。

f49c 把这两件事分开。整段加噪加前馈，纯文本能画回这个人，数据里出现过的粗动作也能做。同一段的另一帧只提供外观，不把损失目标换成和它对不上的设定图。它没有教会数据里没有的关节方向：干净段里背面蹲下的那条写明不拿东西，双手把东西捧在身前的是正面和侧面。雪地要求背面又蹲又捧，肘就反着折了。

## 进展和后面的计划

现在能做的是：纯文本生成这条鲸鱼娘的大约 5 秒片子，场景可以换，动作限于训练片段里同一机位已经出现过的做法。设定图能保住起始姿势，也会挡住必须离开这个姿势的动作。

瓶颈是视角和动作的覆盖，不是再改 60/40 或加步数。51 条、394.8 秒里正面站和坐占了大半。损失只要求画面像这些帧，补不出没有出现过的肘和脚。

下一步保持 f49c 的训法，先补动作。新片段总长不超过 10 分钟：Seedance 35 条、每条 12 秒，TikTok 参考图 22 条、每条 8 秒，大约 7:3。每条都是固定镜头、全身入画，核心动作大约两秒做完再重复，好让 49 帧的窗口能装下一次完整动作。背面的手留在身体前方，走路的两脚分开。不照着书店、林荫道、雪地这三条评测来写。可粘贴的全文在 `project/deepseek/action_prompts.md`，这份清单和训练片段一样不进 git。补完后用同一套 60/40 从头再训一轮。若身份和这些关节都稳住，但 5 秒的后半段仍散，再把窗口加到 81 帧。

## 语音模型：CosyVoice2-0.5B

配音走 `scripts/tts_one.py` 的 `inference_zero_shot`。参考音是 `/home/yi.yang/src/CosyVoice/asset/zero_shot_prompt.wav`，对应文本是「希望你以后能够做的比我还好呦。」音色来自这句参考，不是为鲸鱼娘单独微调的说话人。`text_frontend` 关闭，台词按原文送进去。采样率 24000。

模型分三段，结构来自权重目录里的 `cosyvoice2.yaml`：

1. 语言模型是 Qwen2-0.5B：24 层，隐藏维 896，14 个查询头，2 个键值头。它不直接出波形，而是预测 6561 类语音 token，末尾再加一个结束符。训练损失是语音 token 的交叉熵，文本 token 不计入损失，并按长度归一。采样用重复感知采样，top-p 0.8、top-k 25。
2. 流匹配解码器把语音 token 变成 80 维梅尔谱。说话人条件是 192 维的 x-vector。编码器是 6 层 Conformer，解码器是因果条件流匹配网络。训练时的 classifier-free guidance 比例是 0.2，推理时是 0.7。
3. HiFT 声码器把梅尔谱变成 24 kHz 波形。它带基频预测和对抗训练；这一步的判别器不参与我们现在的推理。

官方训练顺序是先训语言模型，再训流匹配，最后训声码器的 GAN。yaml 里的监督微调学习率是 1e-5。本集群没有做这一步，也没有做 CosyVoice 的强化学习。

## 按主题出一条片子

```bash
python /home/yi.yang/src/videoGenV2/scripts/plan_shot.py \
  --description "在下午的咖啡馆窗边，用大约一秒慢慢抬手挥一下" \

  --shot cafe-wave
```

```bash

```

```bash
python /home/yi.yang/src/videoGenV2/scripts/score_motion.py \
  --shot /home/yi.yang/src/videoGenV2/shots/cafe-wave
```

`snap` 为 true 的片子最大帧差至少是 4。deepseek-wave 的候选 3 会落在这里，候选 2 不会。留下的平滑片子才作为以后换场景和微调的正样本。
